# Приложение для работы с балансом пользователей (Laravel + PostgreSQL)

Веб-приложение для управления балансами пользователей с возможностью пополнения, списания и переводов между пользователями. Реализовано на Laravel с использованием PostgreSQL в качестве базы данных.

## Функциональность

- **Пополнение баланса** - добавление средств на счет пользователя
- **Списание средств** - снятие денег с баланса пользователя
- **Переводы между пользователями** - перевод средств от одного пользователя к другому
- **Просмотр баланса** - получение текущего баланса пользователя
- **История транзакций** - автоматическое логирование всех операций

## Технологии

* PHP 8.2+
* Laravel 12+
* PostgreSQL 17
* Docker (Laravel Sail)

## Установка и запуск


1.  **Клонировать репозиторий:**
    ```bash
    git clone https://github.com/danko/balance-app.git
    cd balance-app
    ```

2.  **Установить зависимости Composer:**
    (Sail использует свой контейнер для этого)
    ```bash
    docker run --rm \
        -u "$(id -u):$(id -g)" \
        -v "$(pwd):/var/www/html" \
        -w /var/www/html \
        laravelsail/php82-composer:latest \
        composer install --ignore-platform-reqs
    ```

3.  **Запустить Docker-контейнеры (Sail):**
    ```bash
    ./vendor/bin/sail up -d
    ```

4.  **Сгенерировать ключ приложения:**
    ```bash
    ./vendor/bin/sail artisan key:generate
    ```

6.  **Выполнить миграции базы данных:**
    ```bash
    ./vendor/bin/sail artisan migrate
    ```

Приложение будет доступно по адресу `http://localhost:8080`.

## Запуск тестов

Для запуска тестов (будет использована `sqlite` в памяти):

## API Документация

Все API endpoints доступны по адресу `/api/` и возвращают JSON ответы.

### 1. Пополнение баланса
**POST** `/api/deposit`

**Параметры:**
- `user_id` (integer, обязательный) - ID пользователя
- `amount` (decimal, обязательный) - Сумма пополнения (должна быть > 0)
- `comment` (string, необязательный) - Комментарий к операции

**Пример запроса:**
```json
{
    "user_id": 1,
    "amount": 100.50,
    "comment": "Пополнение с карты"
}
```

**Пример ответа:**
```json
{
    "user_id": 1,
    "balance": 100.50
}
```

### 2. Списание средств
**POST** `/api/withdraw`

**Параметры:**
- `user_id` (integer, обязательный) - ID пользователя
- `amount` (decimal, обязательный) - Сумма списания (должна быть > 0)
- `comment` (string, необязательный) - Комментарий к операции

**Пример запроса:**
```json
{
    "user_id": 1,
    "amount": 50.00,
    "comment": "Покупка товара"
}
```

**Пример ответа:**
```json
{
    "user_id": 1,
    "balance": 50.50
}
```

### 3. Перевод между пользователями
**POST** `/api/transfer`

**Параметры:**
- `from_user_id` (integer, обязательный) - ID отправителя
- `to_user_id` (integer, обязательный) - ID получателя
- `amount` (decimal, обязательный) - Сумма перевода (должна быть > 0)
- `comment` (string, необязательный) - Комментарий к операции

**Пример запроса:**
```json
{
    "from_user_id": 1,
    "to_user_id": 2,
    "amount": 25.00,
    "comment": "Перевод другу"
}
```

**Пример ответа:**
```json
{
    "from_user": {
        "user_id": 1,
        "balance": 25.50
    },
    "to_user": {
        "user_id": 2,
        "balance": 25.00
    }
}
```

### 4. Получение баланса
**GET** `/api/balance/{user_id}`

**Параметры:**
- `user_id` (integer, обязательный) - ID пользователя в URL

**Пример ответа:**
```json
{
    "user_id": 1,
    "balance": 25.50
}
```

### Коды ответов
- `200` - Успешная операция
- `400` - Некорректные данные (сумма <= 0, некорректный ID)
- `404` - Пользователь не найден
- `409` - Недостаточно средств для списания/перевода
- `422` - Ошибка валидации (например, перевод самому себе)
- `500` - Внутренняя ошибка сервера

## Структура базы данных

### Таблица `users`
Стандартная таблица пользователей Laravel с полями:
- `id` - Уникальный идентификатор
- `name` - Имя пользователя
- `email` - Email пользователя
- `email_verified_at` - Дата подтверждения email
- `password` - Хеш пароля
- `remember_token` - Токен для "запомнить меня"
- `created_at`, `updated_at` - Временные метки

### Таблица `balances`
Хранит текущий баланс каждого пользователя:
- `id` - Уникальный идентификатор
- `user_id` - Ссылка на пользователя (уникальная)
- `balance` - Текущий баланс (decimal 15,2)
- `created_at`, `updated_at` - Временные метки

### Таблица `transactions`
Логирует все операции с балансом:
- `id` - Уникальный идентификатор
- `user_id` - ID пользователя, совершившего операцию
- `type` - Тип операции: `deposit`, `withdraw`, `transfer_in`, `transfer_out`
- `amount` - Сумма операции (всегда положительная)
- `comment` - Комментарий к операции
- `related_user_id` - ID связанного пользователя (для переводов)
- `created_at`, `updated_at` - Временные метки

### Связи между таблицами
- `balances.user_id` → `users.id` (один к одному, каскадное удаление)
- `transactions.user_id` → `users.id` (один ко многим, каскадное удаление)
- `transactions.related_user_id` → `users.id` (один ко многим, установка NULL при удалении)
